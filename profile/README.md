# Your profile goes here

Put your career history in this folder as Markdown files, for example:

- `career.md`: every job, project, degree and certification, with the tools you actually used in each. Be honest and specific; Claude scores postings against this.
- `targets.md` (optional): the roles you want, locations, salary floor, companies to avoid, and whether you need visa sponsorship.

Mark anything you only know a little, or just want to learn, as **"not held"** or **"learning"** so it's scored as a gap, not a skill.

Easiest way: open this repo in Claude Code and say "build my profile/ files from my résumé" and attach your résumé.
